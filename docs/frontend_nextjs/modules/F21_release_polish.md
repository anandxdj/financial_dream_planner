# F21 - Accessibility, Performance & Release Polish

## Accessibility
Keyboard, focus, headings, table semantics, contrast, reduced motion, accessible charts, field-linked errors.

## Performance
Cached useful data first, heavy charts second, no page-wide refetch skeletons, audit client-component boundaries and bundles.

## Release
Cross-browser test, responsive test, copy audit, stale/error/offline states, no fake feature claims, build/lint/test green.
